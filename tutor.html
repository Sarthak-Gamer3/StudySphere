AI tutor connection

The chat interface works now in demo mode. To get genuine AI-generated answers without sending users to another app, connect a server-side API endpoint you control.

  1. Deploy a small backend (for example, a serverless function).
  2. Store your AI provider key as a secret in that host's dashboard.
  3. Set AI_ENDPOINT in config.js to your backend route.
  4. Have the backend validate requests, limit usage, and return a JSON response with an answer field.

GitHub Pages hosts static files only. It cannot securely store a secret API key or run your AI backend by itself.

Privacy & data

Quiz scores, saved notes, and theme preferences are stored in local browser storage in this starter. They do not sync between devices.
